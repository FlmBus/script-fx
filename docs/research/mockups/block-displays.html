Block displays

One display per block type. Each is drawn at the size it gets in the fixed 626 × 266 modal: 190 px high, and as wide as the knob column leaves free (8 knobs → 300 px, 3 → 370, 2 → 440, 1 → 510, none → 590). White and grey only. Block colours and modulator colours stay out of the displays.

white: what the block does / the output grey: the input, a reference, a second channel dashed: targets, thresholds, the neutral line
